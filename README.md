# shadow-ship-spotter

Starter Python project scaffold with uv, NumPy, pandas, Polars, pydantic, matplotlib,
scipy, seaborn, pytest, mypy, black, and ruff.

## Setup

```bash
./install.sh
```

## Common commands

```bash
uv run python run.py
uv run pytest
uv run black .
uv run ruff check .
uv run mypy src
```
